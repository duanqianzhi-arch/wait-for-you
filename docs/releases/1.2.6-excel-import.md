# 1.2.6：网页教务文件导入与开发者署名

2026-10-09；Android versionCode12。固定网站 https://henu-study.pages.dev/ 。

## 使用

iPhone/iPad 在 Safari 登录河南大学教务，进入个人课表，选2026—2027第一学期、“列表”，点击右上角导出。将学校下载的 .xls 保存到“文件”，回网站“我的课表 → 导入我的课表”选择文件，查看识别门数及线上／未排定门数，确认后保存。全程不需要配置快捷指令或安装Excel。旧快捷指令／JSON入口折叠为其他方式。

支持学校实际提供的两种HTML-XLS导出布局：UTF-8的Office表格（标题在课程表上方）与GBK表格（标题和课程两张表）。**不是任意二进制XLS/XLSX的通用识别器。** 文件上限1MiB；普通xlsx、截图、PDF明确拒绝。没有安装额外解析依赖，也不从第三方CDN加载读取器。

第一份真实样例识别9门、14条排定安排、2门未排定；第二份识别10门、13条安排、0门未排定。这些原始个人文件只在本机验证，没有进入源码、发布目录或截图。匿名GBK测试文件是人工构造，并非真实文件脱敏复制。

线上课和只有周次、没有固定星期节次的课程保留底部列表与原始时间说明，不伪造教室、星期或上课时间。日期周次、周视图、编辑、取消、重新同步保护修改沿用原流程。Web没有安卓组件；Android仍保留原网页登录自动导入及组件，更新包只为保持当前界面、署名和包内版本一致。

## 完整性与保存

读取字节、按已验证charset解码。只重建无URL、事件属性及脚本的文本／表格标签，验证html/body/table/tr/td/th闭合后才交给DOMParser，避免浏览器自动补齐截断文件变成“完整课表”。验证学校标题、适配学期、必须列头、行宽、选课状态及重复课程。只有最小课程字段进入已有模型，姓名/学号/教师不保存。

有声明课程门数时必须等于读取行数；没有总门数的完整导出允许预览，但单独提醒核对课程数与名单、勾选确认。没有总数时无法证明学校导出本身是否漏了一整行，不能把文件解析通过等同学校数据完整。损坏/不支持的文件不会覆盖原课表；尚未确认或取消预览不保存。等待文件读取时导航到其他页，不再被结果强制拉回预览。
