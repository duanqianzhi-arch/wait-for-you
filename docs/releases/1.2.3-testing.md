# 1.2.3 多页课表读取修复

日期：2026-10-09；versionCode：9。独立安卓测试版，正式网站保持 1.0.1。

## 已定位的原因

用户提供1.2.2失败诊断：“学校课表为多页报告（共2页），尚未确认全部课程”。第二张图片展示第1页页脚后直接出现第二页标题和表格，课程总数为9。读取器此前在pageCount不为1时立即拒绝，且只允许一张课程表格；因此这次失败已定位到读取器的单页限制。此前对荣耀品牌或线上课的猜测被本次诊断取代。只保留页数／课程数量／版本等结构信息，不保存学生身份、完整课表或原截图。

## 本次修复

- 读取同一个已加载报告文档中的全部课程表格，按每张表格自己的列头提取最小课程字段；第二页列顺序不同也能读取。
- 兼容一个连续表格中重复的打印表头，表头不会作为课程导入；不任意删除或合并真实课程。
- 必须找到完整且不重复的1到N页页码，各页总页数相同，各处课程总数一致，报告学期全部为已适配学期；合并行数必须等于声明课程数。缺页、漏课、页码重复、学期不一致、未知选课状态仍拒绝且保留原课表。
- 输出适配器标记henu-list-2，原生保存格式和本地修改合并机制不变。没有星期节次的课程继续保留在底部“线上／未排定课程”。

本次针对学校将打印页连续放在同一网页里的布局，不会自动点击未知分页按钮、获取其他接口或跳过登录；若学校只加载部分页，仍提示未完整读取。第二页最底部页码尚待用户文本确认，真实荣耀导入需安装后复测。
