# 1.2.5 公开试用：固定更新入口与网页课表

日期：2026-10-09；安卓versionCode：11。推广地址统一为 https://henu-study.pages.dev/ ，版本页为 https://henu-study.pages.dev/android-update 。当前属于公开试用，真实手机验证仍需继续。

## 安卓更新

此前App检查正式网站，但所有课表测试包只发布在Preview，正式站一直1.0.1，因此旧App发现不了新版。本次将最新版安装包、版本元数据与网页一并发布到正式网站，旧版已有的检查更新入口也能发现新版。

首次覆盖安装1.2.5后，App启动会在后台检查固定正式元数据；发现新版显示轻提示，点“去更新”打开同一个版本页。设置保留手动检查；失败可重试，自动检查断网时不弹错误、不影响包内自习查询。返回前台超过6小时会再次检查，不后台持续轮询。下载和覆盖安装由手机浏览器／系统确认，不承诺静默安装。

原生请求只访问公开版本JSON：固定HTTPS地址、禁止重定向、连接/读取超时、16KiB上限。校验包名、数值版本号、合法版本名、对应APK文件名、大小和SHA256格式；输出链接仍为固定正式域名。更新桥只允许包内主文档使用，不接收学校凭据或课表。沿用原包名与签名，无新权限。

后续发布必须递增versionCode，同步版本页、包内版本及JSON的实际大小/哈希，将完整公开目录发布到正式站并核对真实下载。不得只更新Preview后宣称旧App能检查到。旧APK路径保持可用，版本JSON与版本页禁止缓存。

## iPhone 手机内导入

普通网页受浏览器同源规则限制，不能读取另一网站登录后的课表。采用苹果Safari快捷指令提供的“在网页上运行JavaScript”操作，在学校课表页读取课程，再由用户复制到本网站预览保存。没有教务代理后端，不把学校密码或个人课表上传给开发者。

首次配置在网页“我的课表 → 导入 → 首次使用”中有步骤：

1. 新建“导入到等你下课”，开启共享表单，输入类型Safari网页。
2. 添加“在网页上运行JavaScript”，使用快捷指令输入，粘贴网站提供的读取脚本。
3. 添加“拷贝到剪贴板”，复制前一步结果，保存。

以后全程在iPhone完成：Safari登录学校 → 教学安排／个人课表／列表 → 共享运行指令 → 回到等你下课粘贴或点“读取已复制课表” → 预览确认。没有逐门填写课程。首次可能需在快捷指令设置中允许网页脚本。

**当前提供脚本与配置说明，没有一键安装的已签名快捷指令/iCloud分享链接。** 首次配置与真实Safari学校页面仍待iPhone验收；不能将电脑匿名样例通过等同实际手机导入成功。以后可由用户完成配置并在手机验证后分享不含个人课程的指令链接，简化同学首次安装。

读取脚本由 `node scripts/build-safari-reader.cjs` 从当前学校适配器生成，学校适配器更新后必须重新生成。脚本不访问密码、Cookie或网络，只读取已加载的同源课表文档，要求完整分页、学期、课程数及已选状态；输出最小课程字段并恢复临时全局变量。

网页支持导入预览、取消、重新同步保护修改、周切换、跨节与缩放、课程编辑、底部线上／未排定列表及删除。没有桌面组件入口。课表存储在当前浏览器独立键；换浏览器/桌面网页存储环境不会自动同步，清除网站数据会删除课表。浏览器限制存储或空间不足时保留原课表并提示；无效输入不覆盖已有数据。文件入口仅支持本读取脚本输出的JSON，不支持任意Excel/截图。

依据：[浏览器同源规则](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Same-origin_policy)、[苹果网页脚本操作](https://support.apple.com/zh-cn/guide/shortcuts/apdb71a01d93/ios)。
