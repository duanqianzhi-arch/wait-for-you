# 1.1.0 安卓开发测试版

状态：待真实安卓手机验收。正式网站暂保留 1.0.1。本次新增个人课表，不包含桌面组件或通知。

## 安装

使用 `dist/downloads/dengni-xiake-v1.1.0.apk`，包名和签名沿用旧版，版本号 1.1.0 / versionCode 3。直接覆盖安装，先不要卸载旧应用。需要 Android 8 以上、系统 WebView 102 以上。

若提示签名不一致或无法覆盖，停止安装并反馈提示文字；不要通过卸载来掩盖问题。收藏与偏好是否保留仍须在你的手机确认。

## 测试顺序

1. 安装前记下一间已收藏教室；覆盖更新后确认它还在。确认底部有“自习 / 我的课表 / 设置”，顶部校区不变。
2. 打开“我的课表”→“从教务系统导入”，在河南大学原网页登录。账号密码只输入学校页面，不发给助手或开发者。
3. 学校完成登录后应自动读取本学期课程，出现确认页。核对门数、安排数、空地点与学校当前课表；此前观察的 10 门 / 13 条 / 8 条空地点只是对照，不是写死的结果。
4. 先取消一次，确认没有保存。再导入并确认保存，查看本周、上一周与下一周；重点检查单双周与晚上 11—13 节（19:10—21:40）。
5. 点击课程，改教室地址、教学周或节次，保存后关闭 App 再打开，确认仍在。“恢复学校记录”应清除这门课的本地修改。
6. 再次同步相同课表，确认课程不重复、原修改还在。如果学校改变了同一字段、删课或拆分安排，应由你选择。选择“保留我的原安排与修改”会保留原课程安排，并标为本地保留；“采用学校记录”舍弃对应修正。
7. 如改用另一个教务账号，在预览中选择“替换为另一份课表”，不把前一个账号的修正套上去。App 不采集学号，不能自动判断是否换了账号。
8. 取消登录、断网或学校网页失败后，旧课表仍应可离线查看和修改。退出学校导入页后，再导入应重新进入登录页。还要确认教室收藏未被清理。
9. “删除个人课表”需要二次确认，只删除个人课表和本地修正，教室收藏与校区偏好应保留。

## 反馈

反馈手机品牌/型号、Android 版本、WebView 版本、操作步骤、实际提示与期望结果即可。不要发密码、Cookie、学号、完整私人课表或带个人参数的学校 URL。学校网页报错可以描述页面标题与错误文字。

已验证：匿名解析、前端交互、来源限制、原子写入失败回滚、安卓框架测试、同签名构建与包内资源检查。未验证：真实手机登录读取、实际会话清理、覆盖安装保留、各 Android 版本行为。测试通过后再更新正式下载与支持声明。
