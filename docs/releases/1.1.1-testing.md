# 1.1.1 安卓导入修复测试

此包已由 [1.1.2](1.1.2-testing.md) 取代：用户确认能登录，但停在首页，后续已修复学校菜单导航和完整嵌套框架读取。下方为首次清理修复记录。

日期：2026-10-08。版本 1.1.1 / versionCode 4，沿用原包名与签名。正式网站仍为 1.0.1；测试下载在 https://personal-timetable.henu-study.pages.dev/ 。

## 修复原因

用户在 1.1.0 真机上点击“从教务系统导入”后，登录页尚未打开，就出现“学校缓存清理未完成”和 `data:text/html... / ERR_HTTP_RESPONSE_CODE_FAILURE`。

旧代码使用 `loadDataWithBaseURL` 提供清理页。WebView 仍可把内部 `data:` 请求交给资源拦截器；学校域名白名单把它当作非学校请求返回 403，导致清理页不能运行。此前框架模拟未实际渲染 WebView，遗漏了这个边界。

本版改为加载固定 HTTPS 清理地址，并由 App 在资源拦截器中直接返回包内静态 HTML（200），不向学校服务器请求这个地址。清理脚本仍检查学校 origin、清理成功后才打开登录页；其他 `data:`、外站、明文 HTTP 与无效证书仍受原限制。没有扩大登录来源或跳过清理检查。

参考：[Android WebViewClient 官方资源回调说明](https://developer.android.com/reference/android/webkit/WebViewClient#shouldInterceptRequest(android.webkit.WebView,%20android.webkit.WebResourceRequest)) 明确该回调也会收到 `data:` 等非网络请求。

## 手机先测这些

1. 下载 `dist/downloads/dengni-xiake-v1.1.1.apk` 直接覆盖安装；不要卸载旧版。设置中应显示 **1.1.1**，原教室收藏应保留。
2. 我的课表 → 从教务系统导入。等待准备结束，应看到河南大学原登录页，不再出现上述 data 网页错误。
3. 自行登录，等待出现导入确认页；核对课程，再确认保存。不要把密码、Cookie 或私人课表发给维护者。
4. 退出再导入，应重新要求登录。再继续 [完整课表测试](1.1.0-testing.md#测试顺序) 的周次、编辑、重新同步、取消和删除等步骤。

若仍失败，提供当前显示版本、手机型号、Android/WebView 版本，以及不含个人信息的错误文字或截图即可。

本版仍是测试包。网页登录和首次课表导入必须继续真机确认；桌面组件与通知尚未实现。“检查更新”仍检查正式网站，测试更新请使用上面的独立测试下载页。

## 本次验证范围

- 清理页本地响应回归测试先失败、修复后通过；完整 16 项 Robolectric 安卓框架测试和 11 项 Node 测试均通过。
- 同签名 release、debug 与 androidTest 安装包构建通过，实际 APK 包名、versionCode 4、仅 INTERNET 权限、22 个网页资源和原签名已核对。APK 哈希/字节数由产物写入 `android-release.json`。
- 新增 `TimetableImportWebViewTest`：真实 WebView 登录前清理与中断后 localStorage 清理的匿名设备测试。测试只等待学校密码输入框，不登录、不采集账号。
- 本机缺少安卓模拟器加速驱动，两次无加速启动均停留 offline；该设备测试仅编译，**没有执行通过**。不要把框架测试当成实际 WebView 登录成功。可在联网测试设备上运行 `:app:connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=cn.henu.study.waitforclass.TimetableImportWebViewTest`。
