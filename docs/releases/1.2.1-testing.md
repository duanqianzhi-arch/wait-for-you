# 1.2.1 导入兼容与组件刷新修复

日期：2026-10-09；versionCode：7。独立安卓测试版，正式网站仍为 1.0.1。

## 下载与覆盖更新

[测试下载页](https://personal-timetable.henu-study.pages.dev/android-update.html?versionCode=6)。下载 1.2.1，直接覆盖安装，**不要卸载原应用**。更新后在设置确认版本 1.2.1。App 内检查更新仍查询正式站，当前测试请用此链接。

## 本次修复

- 今日课程与本周课表刷新时先替换动态内容，避免手机桌面复用旧布局后持续追加卡片、节次行和旧冲突提示。真实重叠课程仍保留冲突提示。
- 清理昨日高亮并突出今日，避免周四、周五同时保持深色背景。删除课表后移除旧卡片，重新导入后恢复课程区域。
- 学校课程状态“选中”和“已选中”统一成内部“选中”，其余未知状态仍拒绝；不修改原生存储格式。
- 无地址、无具体节次的线上课不会阻止整个课表规范化；有周次而无星期/节次的记录保留在待核对安排，不编造时间或放入某个固定格子。这个保留行为原本已存在，本次增加端到端回归。
- 导入失败时区分框架加载、课程数量、报告页数、未识别格式与选课状态，附 App、Android API 和 WebView 版本。仅显示固定提示及有界计数，不回显学校姓名、学号、课程内容、URL、Cookie 或未知错误文本。

用户提供的“已选中”来自学校二维课表示例；该状态已通过匿名列表样例验证兼容。荣耀 400 的实际失败原因仍需更新后复测，不能仅凭品牌或截图认定已经解决。多页报告仍要求确认完整性，不因兼容修复而跳过课程总数/页数检查。

## 手机复测

1. 覆盖更新后打开 App，确认原课表、本地修改和收藏仍在。
2. 回到桌面点组件的刷新，反复刷新三次：今日课程数量应稳定，本周只有 13 节；昨天日期不再标黑，已经解决的旧冲突不再留下。
3. 若桌面仍显示更新前的旧布局，移除这两个桌面组件再添加，**不要卸载 App**。无需为了组件刷新重新导入个人课表。
4. 荣耀同学重新导入并在学校原网页自行登录；查看是否出现确认预览，包括未排具体时间的课程。若仍失败，仅反馈顶部失败原因和版本行，截屏时避开姓名学号。
5. 删除个人课表后，已有组件不留旧课程；重新导入后组件正常显示。真实时间重叠仍可点开 App 核对。
